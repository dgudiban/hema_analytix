# hema_analytix

AI-Powered Blood Laboratory Report Intelligence System

HemaAnalytix analyzes blood laboratory reports, identifies abnormal
biomarkers, tracks changes over time, and provides AI-powered
explanations.

## Main Features

- Blood report upload
- Laboratory result extraction
- Biomarker normalization
- Abnormal result detection
- Historical biomarker tracking
- Trend visualization
- AI-powered explanations
- Conversational AI
