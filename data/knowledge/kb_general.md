# BloodIQ general knowledge (hand-written, educational)

Each `##` section is one retrieval chunk. Metadata lines (`id:`, `title:`)
are parsed by kb_loader; everything after them is the chunk text.

## id: kb-gen-01
## title: How BloodIQ classifies results
BloodIQ assigns every extracted result one of four statuses: LOW, NORMAL,
HIGH, or unknown. The status is computed deterministically by comparing the
measured value against the reference range printed on that specific lab
report. If the value is below the report's lower limit it is LOW; above the
upper limit it is HIGH; inside the range it is NORMAL. When the report does
not print a reference range for a test, the status is unknown — BloodIQ never
guesses and never substitutes a universal or textbook range, because normal
ranges differ between laboratories, analyzers, and populations.

## id: kb-gen-02
## title: About reference ranges on lab reports
A reference range is the interval of values a laboratory considers typical
for a given test, and it is printed on the report next to each result. Ranges
can legitimately differ between labs because they depend on the measurement
method, the analyzer, the reagents, and the reference population the lab
studied. That is why BloodIQ always uses the range from the report being
read rather than any fixed table of ranges. A value flagged LOW or HIGH is
outside the lab's own expected interval; it is a prompt to discuss the
result with a healthcare professional, not a diagnosis by itself.

## id: kb-gen-03
## title: Trends in BloodIQ
A trend compares the same biomarker across multiple reports over time.
BloodIQ only compares values reported in compatible units, and it labels the
direction as improving, declining, or stable using a 5% tolerance band:
changes smaller than 5% count as stable. Whether "improving" is good news
depends on the biomarker and on which direction is desirable for it; the
trend label describes the direction of change, and the reference range from
each report still determines whether each individual value was LOW, NORMAL,
or HIGH.

## id: kb-gen-04
## title: Calculated results in BloodIQ
Some results are derived from measured values instead of being measured
directly. BloodIQ computes two of them. Non-HDL cholesterol equals Total
Cholesterol minus HDL cholesterol, and it represents the cholesterol carried
by all lipoproteins other than HDL. Transferrin saturation equals serum iron
divided by TIBC (total iron-binding capacity), multiplied by 100, and it is
expressed as a percentage. Calculated results are always labeled as
calculated so they can be distinguished from values the laboratory reported.

## id: kb-gen-05
## title: Traceability and test subtypes
Laboratories may report closely related but distinct tests, and BloodIQ
keeps them separate instead of merging them silently. Examples include RDW-CV
versus RDW-SD, 25-hydroxy vitamin D versus 1,25-dihydroxy vitamin D, total
calcium versus ionized calcium, standard CRP versus high-sensitivity CRP,
and serum folate versus red-cell folate. For every result BloodIQ preserves
the original test name exactly as printed, the original unit, and the
report-specific reference range, alongside the standardized biomarker name
it was mapped to. This preserves a full audit trail from the PDF to the
displayed result.

## id: kb-gen-06
## title: Safety boundary
BloodIQ is an educational and informational tool. It does not diagnose
conditions, prescribe medication, recommend treatments or dosages, or make
emergency medical decisions, and it is not a substitute for professional
medical advice. Explanations generated by the AI describe what biomarkers
measure and what the extracted values show relative to the report's own
reference ranges. Any health concern, abnormal result, or question about
treatment should be discussed with a qualified healthcare professional.
In an emergency, seek emergency care rather than consulting this tool.
